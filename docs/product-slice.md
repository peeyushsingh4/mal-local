# Product Definition: MAL Local

## User Persona
Riya, a 28-year-old Bandra West resident who wants a lightweight way to discover and share neighborhood services and goods without downloading heavy apps or joining multiple WhatsApp groups.

## Problem
Neighborhood services, goods, and help requests are scattered across WhatsApp groups, notice boards, and word of mouth. There's no single, lightweight, privacy-respecting place to browse and post.

## Workflow
Browse listings feed → View details → Save/Contact/Close → Create new listing with AI-assisted description → View neighborhood pulse

## Categories
- Services (🔧)
- Goods (📦)
- Lending (🤝)
- Food (🍱)
- Requests (🙏)
- Skills (🎓)

## Out of Scope
- Payments
- Delivery
- Chat/Messaging
- KYC
- Moderation dashboard
- User accounts/auth
- Backend infrastructure
- Real-time sync
- Push notifications
- Image upload

## Custom Feature
**Neighborhood Pulse**: A dashboard showing listing activity trends, most active categories, and community activity score.
